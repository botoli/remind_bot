# Medbot

Небольшой Telegram-бот на Go для одного пользователя. Он показывает сохранённое расписание и записывает твою отметку о приёме и указанное тобой время. Бот не меняет назначение и не подсказывает, что делать с пропущенной дозой.

## Запуск

1. Создайте бота через BotFather и узнайте свой числовой Telegram User ID.
2. Скопируйте `.env.example` в `.env`, заполните `TELEGRAM_BOT_TOKEN` и `ALLOWED_USER_ID`. `.env` не отслеживается Git.
3. Проверьте назначения и время в `config/config.yaml`. Время 01:30 относится к ночи **после** 20:00 того же дня расписания.
4. Выполните `go run ./cmd/bot` из корня проекта и отправьте боту `/start` с разрешённого личного аккаунта. Появятся три кнопки внизу чата. Программа должна работать постоянно.

Данные хранятся в `data/medbot.db` (SQLite). Путь к конфигу можно задать через `MEDBOT_CONFIG`, путь к базе — через `MEDBOT_DB`. Изменения YAML применяются после перезапуска. Не запускайте две копии бота с одним токеном одновременно.

## Поведение

- **Сегодня** показывает текущий день расписания; до первого дневного приёма это предыдущий день.
- **Уже выпил** → выбери один из четырёх приёмов → нажми «Сейчас», «15 минут назад», «30 минут назад» или введи время вручную. Можно выбрать вчерашний день. Если приём уже отмечен, бот покажет сохранённое время и предложит его исправить.
- **История** показывает число отмеченных приёмов за семь последних дней. Расписание и помощь доступны кнопками на главном экране. Старые команды `/today`, `/schedule`, `/history` и `/help` также работают.
- В назначенное время отправляется напоминание. «Выпил сейчас» отмечает текущее время, «Указать время» открывает выбор времени, «Через 15 мин» создаёт повтор (максимум три раза).
- Бот удаляет сообщения, которые отправляются при нажатии на нижние кнопки, а свой экран обновляет в том же сообщении. Введённое вручную время тоже удаляется после обработки. Сообщение с напоминанием после нажатия кнопки обновляется.
- В SQLite отдельно хранятся время нажатия и сообщённое время приёма. Для старых отметок, сделанных до обновления, время приёма не указано; бот не выдаёт время прежнего подтверждения за время приёма.
- Если за 45 минут не было ни подтверждения, ни запроса повтора, бот один раз присылает сообщение «не отмечен».
- После простоя бот восстанавливает напоминания, если с назначенного времени прошло меньше 45 минут. Более старые первичные сообщения не рассылаются задним числом.
- Сообщения и кнопки от других Telegram User ID игнорируются. `/start` должен прийти из личного чата.

Запуск без настроенных переменных не подключается к Telegram. Для остановки используйте Ctrl+C.

## Docker Compose

После заполнения `.env` запустите `docker compose up -d --build`, затем отправьте `/start`. База хранится в именованном томе `medbot_data`. После изменения `config/config.yaml` выполните `docker compose restart medbot`.
